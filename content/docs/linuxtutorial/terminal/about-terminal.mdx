在日常使用中，我们经常会把“打开终端”，“打开命令行”，“使用Shell”混为一谈，因为在实际操作中，它们三个往往是同时出现的。但从概念上来说，它们实际上是三个不同的东西

为和如此说呢？Terminal实际上是负责输入输出的界面，而非Shell本身。我们在Terminal中输入文字，Terminal再将这些输入交给Shell，同时把Shell产生的输出显示出来。Terminal是一个让我们能够与Shell进行交互的窗口。  

我们通过Terminal去向Shell下命令，Shell接收到命令后去翻译给内核，后执行这一条命令。我们无法直接与Shell交流，Terminal也无法直接与内核交流。

虽然看起来很繁琐，但是其实很高效并且简洁。并且这个是作为一个最基本的使用电脑的方式，同时也是一个很高效的方式。

好的接下来可以直接打开你的命令行，找不到？直接搜索[Terminal]就可以。以下是一些基本的指令。

### 目录与路径操作
`pwd`：显示当前所在的绝对路径。  
`cd` 目录名：切换到指定目录（如 cd /home 或 cd .. 返回上一级）。  
`ls`：列出当前目录下的文件和子目录（常用 -l 查看详情，-a 查看隐藏文件）。  
`mkdir` 目录名：创建一个新目录。  
`touch` 文件名：创建一个空白文件或更新已有文件的修改时间。  
`cp` 源文件 目标文件：复制文件或目录。  
`mv` 源文件 目标路径：移动文件、重命名文件。  
`rm` 文件名：删除文件（加 -rf 参数可强行递归删除目录）。  
`cat` 文件名：查看文件的全部内容。  
`less` 文件名：分页查看较长的文件内容。  
`echo` 文本：在终端打印出文字或变量值。  
`grep` 关键词 文件：在文件中搜索匹配的字符串。  

为什么会有路径？  

很简单，为了方便人来管理文件，理论上来说其实可以把所有的文件全部都放在一个文件夹里面，并且程序仍然能够正常运行。  
但是我们并不会那样做，因为我们无法管理他，所以我们建造了许多的目录去隔离各个文件，以方便我们分门别类以及管理。  
于是便有了目录结构，我们处理某些文件，总是要找到文件所在地。  

这里有一个简单的技巧，一般来说`~`代表着home目录，也就是用户所在地的目录  

例如：`yz_cf@fedora:~$`其中所在的目录就是用户的home目录  

以及 `.`一般来说是当前目录，`..`一般来说是当前目录的上级目录  
例如`yz_cf@fedora:~/project/IX:$`  
假如其中有文件在其中，你不需要从头打一遍路径，只需`./abcd123`即可  
`cd`命令同理  
执行`cd ..`就是返回上一级目录  
非常简单，只要理解这些就能够理解绝对路径与相对路径之间的差别。
